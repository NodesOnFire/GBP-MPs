# GBP-MPs
A collection of compact Mathematical Programs for the Graph Burning Problem
#

```mermaid
graph MPs;
    Mathematical Programs --> Mixed-Integer Linear Programs;
    Mathematical Programs --> Constraint Satisfaction Problems;
    Mathematical Programs --> Integer Linear Programs;
    Mathematical Programs --> Quadratic Unconstrained Binary Optimization problems;
    CSP-->COV-CSP;
    CSP-->COV-ILP;
    CSP-->GBP-IP;
```
